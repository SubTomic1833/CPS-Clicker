# ⚡ CPS Test

A simple CPS Clicker game!

Try it for yourself : https://subtomic1833.github.io/CPS-Clicker/

## How to play !
-Use your mouse to measure you clicks per second (CPS).

## Features
-Several time options (5, 10, 15)
-Statistics dashboard using localStorage that features :
  1: Games Played
  2: Total Clicks
  3: Average CPS
-Best CPS indicator
